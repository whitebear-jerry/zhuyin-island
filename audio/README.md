# 自訂標準注音錄音資料夾 (`audio/`)

本應用程式採用「**MP3 音檔優先 ＋ 台灣繁中語音合成 (`zh-TW` `SpeechSynthesis`) Fallback**」雙層架構：

1. 當您點擊或出題播放某個注音符號（例如 `ㄅ`）時，程式會優先偵測 `./audio/ㄅ.mp3` 是否存在（也會相容標準編碼檔名或同目錄下的 `ㄅ.mp3`）。
2. 若檔案存在且可播放，會立即使用真人/老師預錄的 `.mp3` 聲音，達到 100% 台灣國語正音教學標準。
3. 若尚未放入 `.mp3`，系統會自動以精選的台灣同音字/韻呼近似字送給 `zh-TW` 語音引擎發音，不會無聲卡住。

## 建議最優先補錄的 MP3 檔案清單（依瀏覽器失真度排序）

瀏覽器 TTS 天生擅長念「完整漢字」，不擅長單獨念「純無聲子音/氣音」或「單獨韻母」，因此以下檔案放入 `audio/` 後體感提升最大：

1. **極易失真／夾帶額外母音（最優先）**：
   - `ㄐ.mp3`、`ㄑ.mp3`、`ㄒ.mp3`（純舌面音，TTS 常念成「雞七西」或拖長過重）
   - `ㄓ.mp3`、`ㄔ.mp3`、`ㄕ.mp3`、`ㄖ.mp3`（純捲舌聲母呼音，TTS 念漢字容易偏重或帶捲舌過度）
   - `ㄗ.mp3`、`ㄘ.mp3`、`ㄙ.mp3`（舌尖前清音）
   - `ㄜ.mp3`、`ㄝ.mp3`、`ㄛ.mp3`（單韻母口型差異極細，`ㄝ` 缺獨立常用單字）
   - `ㄣ.mp3`、`ㄥ.mp3`（前鼻音 vs 後鼻音，`ㄥ` 無常用單字）
2. **中度容易偏音（建議第二批補錄）**：
   - `ㄅ.mp3`、`ㄆ.mp3`、`ㄇ.mp3`、`ㄈ.mp3`、`ㄉ.mp3`、`ㄊ.mp3`、`ㄋ.mp3`、`ㄌ.mp3`、`ㄍ.mp3`、`ㄎ.mp3`、`ㄏ.mp3`
   - 依教育部國語正音，聲母呼音帶輕微央元音（如 ㄅㄛ 輕短），真人錄製會比 TTS 唸「波、坡、摸」更輕巧好聽。
3. **其餘韻母（TTS 準度較高，有餘裕可統一補齊）**：
   - `ㄧ.mp3`、`ㄨ.mp3`、`ㄩ.mp3`、`ㄚ.mp3`、`ㄞ.mp3`、`ㄟ.mp3`、`ㄠ.mp3`、`ㄡ.mp3`、`ㄢ.mp3`、`ㄤ.mp3`、`ㄦ.mp3`

## 檔案命名與靜態網站（GitHub Pages）同步方式

- 直接以注音符號本身命名：`<符號>.mp3`
- 例如：`audio/ㄅ.mp3`、`audio/ㄆ.mp3`、`audio/ㄝ.mp3`、`audio/ㄥ.mp3`
- **本機開發**：放在 `audio/` 資料夾內即會自動偵測生效。
- **GitHub Pages 等純靜態託管**：請同時把放入的檔名加入 `audio/manifest.json`（例如 `{"files": ["ㄝ.mp3", "ㄥ.mp3"]}`），程式就能零錯誤立即切換為真人 MP3。
- 建議錄製格式：單聲道 MP3（44.1kHz, 128kbps），前後裁去靜音空白（trim silence < 50ms），長度約 0.5～0.9 秒最跟手。
